# Documentation

작업의 범위·우선순위·수용 조건과 재개 지점은 `workflows/<run-id>/brief.md`에서 관리합니다.

- [dotagents 개편 작업 절차서](workflows/dotagents-renewal/brief.md): P0~P3의 기능별 구현 범위, PR 의존 관계와 검증 결과.

루트 `README.md`보다 긴 설계 설명과 운영 문서를 보관합니다. 구조의 기준 문서는 루트 `README.md`이며 승인된 기능 설계는 `designs/`에서 한국어 단일본으로 관리합니다. 모델·워크플로우 변경의 재현 가능한 평가 조건과 관찰 결과는 `evals/`에 둡니다.

[전역 설치 layout과 소유권](designs/install-layouts.md)은 legacy·managed 모드의 링크, 사용자 설정, 기록과 명시적 이행 계약을 설명합니다.
