# dotagents 설치·진단 개편 기록

2026-11-18 개편에서 설치기와 진단기가 같은 owned 스킬 목록을 쓰도록 통합했다. 기존에는 스킬 하나를 추가할 때마다 전역 설치, 프로젝트 설치, 진단기에서 이름을 따로 수정해야 했다.

## 설계 결정

| 대상 | 결정과 이유 |
| --- | --- |
| owned 스킬 | 설치기는 `agents/skills/owned/<name>/SKILL.md`에서 스킬을 열거하고, 진단기는 실제로 설치된 체크아웃에서 같은 규칙을 적용한다. 레지스트리는 출처와 지원 정보를, 설치 기록은 실제 링크와 백업을 관리한다. [스킬 관리](../../../agents/skills/README.md) |
| 설정과 공유 디렉터리 | `legacy`는 원본을 직접 링크한다. 다른 도구와 스킬 디렉터리를 함께 쓰거나 호스트 사용자 설정을 보존하는 설치에는 `managed`를 제공한다. [설치 레이아웃과 소유권](../../designs/install-layouts.md) |
| 외부 스킬 | 사용자가 선택한 스킬만 검토한 커밋에서 설치한다. 외부 스킬의 출처와 설치 기록을 별도로 관리해 전역 설치를 제거해도 독립적으로 갱신·제거할 수 있다. [외부 스킬 관리](../../external-skills.md) |
| 프로젝트 초기화 | 프로젝트가 자기 지침을 소유할 수 있도록 기존 파일을 보존하고, 명시적으로 적용할 때 필요한 초안만 복사한다. [프로젝트 준비](../../project-readiness.md) |
| 셸·Git 설정 | 선택 환경 프로필은 chezmoi로 미리보기와 명시적 적용을 제공한다. 링크 설치와 파일 복사 방식에서 충돌·복원 동작이 어떻게 달라지는지 임시 디렉터리에서 비교했다. [환경 배포 실험](../../designs/environment-profile.md) |

## 검증 증거

당시 통합 검사에서 임시 홈과 프로젝트로 회귀 테스트 15개와 chezmoi 2.74.1을 사용한 배포 비교 8개를 통과했다. 전역 재설치·제거 뒤에도 기존 사용자 설정과 별도로 설치한 외부 스킬이 보존됐고, 전역 설치를 제거한 뒤 프로젝트 초기화·진단도 성공했다.

현재 체크아웃은 `make check`로 검증한다. chezmoi를 준비한 환경에서는 `./environment/compare.sh`로 동일한 배포 비교를 재실행할 수 있다. [저장소 검사](../../../tooling/README.md) · [비교 환경 준비](../../designs/environment-profile.md#실험-조건과-재현)

호스트가 실제로 스킬을 발견해 실행하는지, 커밋 훅을 신뢰하는지는 별도로 확인해야 한다. 프로젝트·환경 명령의 선택에 대해서는 네 개의 시나리오에서 모델의 판단을 평가했다. [평가 조건과 결과](../../evals/renewal-interface-decisions.md)
