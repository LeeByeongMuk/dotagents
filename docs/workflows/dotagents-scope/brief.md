# dotagents 역할 정리 기록

2026-11-18 완료한 #51에서 공통 규칙, 선택 스킬과 프로젝트별 설정의 적용 범위를 정리했다. [자산 배치 기준](../../../agents/README.md#새-자산의-위치-정하기)

## 결정 기록

- 기술 스택과 관계없이 적용할 개인 기준은 공통 규칙으로 관리한다. 여러 프로젝트에서 활용할 작업 절차에는 스킬의 실행 조건을 적는다. [규칙 작성 기준](../../decisions/0002-rule-authoring-criterion.md) · [스킬 선택](../../../agents/skills/README.md)
- 프로젝트가 사용하는 기술·도메인 관례·검증 명령은 해당 프로젝트가 소유한다. [프로젝트 준비](../../project-readiness.md)
- 셸·Git 설정 예제는 환경 프로필에서 따로 적용한다. [환경 프로필](../../../environment/README.md)

## 검증 증거

#51 당시 문서 안내에 관한 수용 조건(`AC-01`, `AC-02`, `AC-04`)의 검증으로 변경 문서 6개의 내부 링크 126개를 확인했다. 그중 16개는 대상 문서의 제목 앵커까지 확인했다.

같은 시점에 `make check`, `git diff --check`, 기존 전역 설치의 `make doctor`가 통과했다. 환경 프로필은 기본 검사까지 수행했고 실제 chezmoi 실행은 바이너리 부재로 생략했다. [검증 명령과 범위](../../../tooling/README.md)
