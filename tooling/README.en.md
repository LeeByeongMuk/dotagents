# Tooling

This area contains dotagents installation, removal, generation, update, diagnostics, and verification code. `scripts/workflow.sh` manages product-development state, approvals, and recovery; `tests/workflow_test.sh` verifies its boundaries. The network-enabled `scripts/check-sources.sh` verifies that every locked external skill path exists at its pinned commit. See the root `README.en.md` for user commands and the full layout.
