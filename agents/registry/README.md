# Registry

기계가 읽을 수 있는 내부·외부 자산 목록과 잠금 정보를 TOML로 관리합니다. `skills.toml`과 `sources.lock`에는 제품 개발 워크플로우와 선택 공급자의 검토 출처가 등록되어 있습니다. `tooling/scripts/check-sources.sh`는 GitHub API로 각 잠금 커밋의 소스 상대 경로를 검증합니다. 현재 설치기는 owned 스킬을 직접 연결하며 이 레지스트리에서 외부 자산을 자동 다운로드하지 않습니다.

향후 항목은 공통적으로 안정적인 ID, 출처, 버전 또는 커밋, 라이선스, 지원 호스트, 적용 프로필, 기본 활성화 여부를 명시합니다. 비밀 값 대신 필요한 환경 변수 이름만 기록합니다.
