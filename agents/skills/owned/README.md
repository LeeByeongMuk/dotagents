# Owned skills

`fsd-refactor`는 이미 FSD를 채택한 프로젝트에서 동작·렌더 결과·URL·API를 보존하며 구조 위반을 조사·교정합니다.

직접 작성하고 여러 프로젝트에서 재사용할 스킬을 `<name>/SKILL.md` 형태로 보관합니다. 현재 `product-development-workflow`가 구현 없는 `plan`, Brief 중심 `lean`, 요청 시 Claude·Codex Model Fit, 자율 실행과 호스트별 검증을 제공합니다. `dotagents-promote`는 세션에서 발견한 프로젝트 무관 관례를 격리된 worktree 브랜치에서 이 저장소로 승격합니다. `usage-guide`는 기능을 화면 캡처나 목업, 번호 설명, 자주 묻는 질문을 갖춘 최종 사용자용 16:9 사용 가이드 PDF와 단일 HTML로 만듭니다.
