# Personal defaults for Gemini CLI

프로젝트의 `GEMINI.md`, `AGENTS.md`, 로컬 규칙이 이 개인 기본값보다 우선한다.

공통 규칙 원본은 전역 설치 시 `~/.agents/rules/`, 프로젝트 설치 시 `.agents/rules/`에 있고 재사용 프롬프트 원본은 같은 기준의 `prompts/`에 있다. 호스트가 이 파일 밖의 문서를 자동으로 읽지 않으므로, 작업 종류에 맞는 규칙 문서를 직접 읽어야 적용된다. 커밋 메시지 기본 규칙은 `rules/git.md`에 있다.

Gemini 전용 설정과 인증은 도구의 안전한 설정 저장소에서 별도로 관리한다. 이 파일에는 공통 규칙 본문을 복제하지 않는다.
