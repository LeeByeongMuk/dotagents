# Personal defaults for Codex

프로젝트에 더 가까운 `AGENTS.md`와 프로젝트 로컬 지침이 이 개인 기본값보다 우선한다.

공통 규칙 본문은 이 파일 아래에 함께 실려 있으므로 따로 읽지 않아도 적용된다. 원본은 전역 설치 시 `~/.agents/rules/`, 프로젝트 설치 시 `.agents/rules/`에 있고 규칙을 고칠 때는 그 원본을 고친다. 커밋 메시지 기본 규칙은 `rules/git.md`이며 Codex에서는 훅이 같은 규칙을 검사한다.

Codex의 승인·샌드박스·모델 설정은 `config.toml`에서 별도로 관리한다.
