# Personal defaults for Codex

프로젝트에 더 가까운 `AGENTS.md`와 프로젝트 로컬 지침이 이 개인 기본값보다 우선한다.

공통 규칙 원본은 전역 설치 시 `~/.agents/rules/`, 프로젝트 설치 시 `.agents/rules/`에 있고 재사용 스킬 원본은 같은 기준의 `skills/`에 있다. 호스트가 이 파일 밖의 문서를 자동으로 읽지 않으므로, 작업 종류에 맞는 규칙 문서를 직접 읽어야 적용된다. 커밋 메시지 기본 규칙은 `rules/git.md`에 있다.

Codex의 승인·샌드박스·모델 설정은 `config.toml`에서 별도로 관리한다. 이 파일에는 공통 규칙 본문을 복제하지 않는다.
