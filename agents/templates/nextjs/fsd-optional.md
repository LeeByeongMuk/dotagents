# Optional Feature-Sliced Design rules

이 문서는 FSD를 명시적으로 채택한 프로젝트만 사용한다. 현재 디렉터리와 import alias에 맞춰 레이어 이름을 확정하고 ESLint 등 자동 검증과 함께 적용한다.

- 상위 레이어는 하위 레이어만 참조한다.
- 같은 레이어의 독립 슬라이스를 직접 결합하지 않는다.
- 슬라이스 외부에서는 공개 API를 통해 접근한다.
- 프레임워크 라우팅 디렉터리는 얇게 유지하고 합성 책임의 위치를 프로젝트에서 정의한다.
- `pages` 같은 FSD 용어가 프레임워크 예약 디렉터리와 충돌하면 프로젝트가 대체 이름을 명시한다.

레이어 구성, 예외, alias, 자동 검사 도구를 결정하지 않았다면 이 규칙을 강제하지 않는다.
