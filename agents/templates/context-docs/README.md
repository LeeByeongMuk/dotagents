# 살아있는 컨텍스트 문서 템플릿

대상 프로젝트가 복사해 쓰는 템플릿이다. dotagents에는 규약과 템플릿만 유지하고, 문서 본문은 각 프로젝트에 산다.

## 위치

- 기본: 모듈 루트의 `.ai-context/`. 단일 모듈 저장소는 저장소 루트에 하나만 둔다.
- 프로젝트가 다른 관례를 쓰면 프로젝트 `AGENTS.md`에 위치를 기록하고 그것을 따른다.

## 문서 종류와 생성 시점

- `domain-overview.md`: 모듈이 소유하는 도메인 규칙이 처음 생길 때 생성한다.
- `interface-contract.md`: 다른 모듈이나 클라이언트가 소비하는 공개 인터페이스가 생길 때 생성한다. 기계 판독 스펙(openapi 등)이 이미 있으면 복제하지 않고 경로로 연결한다.
- `integration-map.md`: 첫 외부·내부 연동이 생길 때 생성한다.

## 규칙

- 현재 상태만 기술하고 변경 이력·계획·회고는 Git에 맡긴다.
- 문서를 바꾸는 변경과 같은 변경 단위에서 갱신한다.
- 하나의 사실은 한 문서에서만 원본으로 유지하고 다른 문서는 경로로 참조한다.
- 한국어로 작성하고 확인한 사실만 기록한다.
- 비밀 값과 실제 인증 정보를 넣지 않는다. 환경 변수는 이름만 기록한다.
- 내용 없는 문서를 미리 만들지 않는다.
