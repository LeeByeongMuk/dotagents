# 프로젝트 컨텍스트 준비

이 파일은 dotagents `agents/templates/context-docs/project-readme.md`에서 복사한 로컬 안내다. 전역 설치나 원본 저장소 링크 없이 사용할 수 있다. 실제 도메인 사실을 담은 문서는 프로젝트에서 필요할 때 만든다.

1. 기존 `AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, 문서와 설정을 읽고 프로젝트가 쓰는 규칙·컨텍스트 위치를 따른다. 다른 위치가 원본이면 이 안내를 그 경로로 교체하거나 삭제한다.
2. `AGENTS.md`의 자리표시자를 확인한 사실로 바꾸거나 불필요한 항목을 삭제한다. 새 프로젝트 관례가 필요하면 사용자의 최신 실사용 저장소에서 관련 지침과 패키지 메타데이터를 읽고 출처 경로·커밋을 기록한다. 이 템플릿을 실사용 관례의 근거로 삼지 않는다.
3. 검증 명령은 프로젝트의 패키지 스크립트·CI·빌드 설정에서 확인해 `AGENTS.md`에 적는다. 명령의 존재와 실제 성공을 구분하고 실행 결과를 작업 보고에 남긴다. 이 초기화 도구는 프로젝트 명령을 실행하지 않는다.
4. 모듈이 도메인 규칙을 소유하면 `domain-overview.md`, 공개 인터페이스가 생기면 `interface-contract.md`, 연동이 생기면 `integration-map.md`를 이 위치나 기존 문서 위치에 만든다. 내용 없는 문서를 미리 만들지 않는다.

컨텍스트에는 현재 확인한 책임·규칙·계약·연동만 한국어로 적는다. 한 사실의 원본은 하나로 유지하고 다른 문서에서는 경로를 참조한다. 코드의 도메인 규칙·공개 인터페이스·연동이 바뀌면 같은 변경에서 문서를 갱신한다. 변경 이력은 Git에 맡기고 비밀 값은 쓰지 않는다.

이 안내의 존재만으로 프로젝트의 컨텍스트가 완성되거나 검증이 통과한 것은 아니다.
