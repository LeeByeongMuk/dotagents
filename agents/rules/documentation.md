# Living context documentation

- 모듈에는 현재 상태를 설명하는 컨텍스트 문서(도메인 개요, 인터페이스 계약, 연동 지도)가 있을 수 있다. 있으면 코드 전체를 다시 탐색하는 대신 그 문서를 출발점으로 삼는다.
- 변경이 도메인 규칙, 공개 인터페이스, 연동 지점을 바꾸면 같은 변경 단위에서 영향받은 컨텍스트 문서를 함께 갱신한다.
- 컨텍스트 문서는 현재 상태만 기술한다. 변경 이력·계획·회고를 넣지 않고 역사는 Git에 맡긴다.
- 하나의 사실은 한 문서에서만 원본으로 유지하고 다른 문서는 경로로 참조한다.
- 프로젝트의 기존 문서 관례가 우선한다. 관례가 없으면 같은 원본의 `templates/context-docs/` 구조를 기본으로 사용한다.
