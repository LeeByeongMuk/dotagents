# AI 자산 프로필

규칙·워크플로우·스킬·훅·연동을 조합하는 프로필을 위한 영역입니다. 현재 실제 TOML 프로필과 프로필별 설치·override 합성은 제공하지 않습니다. 소비하는 생성기와 함께 추가합니다.

[스킬 레지스트리](../registry/README.md)의 `profiles` 값도 현재 설치 대상을 거르지 않습니다. 셸·Git 설정을 적용하는 [개발 환경 프로필](../../environment/README.md), Codex의 [CLI 프로필](../adapters/codex/README.md)은 각각 별도 기능입니다.
