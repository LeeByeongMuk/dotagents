# Routing

요청의 종류, 구현 권한, 제품 결정의 필요성, 위험과 증거 요구에 따라 단일 스킬 또는 워크플로우를 선택하는 규격을 보관합니다. 요구가 확정된 작은 수정·단일 버그·설명·사실 조사는 프로젝트 일반 절차인 `direct`, 제품 문제 탐색·대안 비교·기획 요청은 구현하지 않는 `plan`, 구현이 승인된 새 제품·의미 있는 기능은 `Brief → Execute → Verify`의 `lean`으로 라우팅합니다. 구현이 승인됐고 규제·민감한 보안 경계·비가역 변경·공식 인수인계의 단계 증거가 필요하거나 사용자가 audited 산출물을 명시적으로 요청한 경우에만 같은 스킬의 `audited` 경로를 선택합니다. 스킬의 description이 세 호스트의 실제 진입 규칙이며 Claude Code와 Codex는 같은 결과 계약을 공유합니다.
