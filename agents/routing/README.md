# Routing

요청의 종류, 제품 결정의 필요성, 위험과 증거 요구에 따라 단일 스킬 또는 워크플로우를 선택하는 규격을 보관합니다. 새 제품이나 아직 무엇·왜를 결정할 기능은 `product-development-workflow`의 `Brief → Execute → Verify` 기본 경로로, 요구가 확정된 작은 수정·단일 버그·설명·조사는 프로젝트의 일반 절차로 라우팅합니다. 규제·민감한 보안 경계·비가역 변경·공식 인수인계에는 같은 스킬의 `audited` 경로를 선택합니다. 스킬의 description이 세 호스트의 실제 진입 규칙입니다.
