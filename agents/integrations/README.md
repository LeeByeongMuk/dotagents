# 외부 연동

[문서 목록](../../docs/README.md) · [레지스트리와 잠금](../registry/README.md)

외부 자산의 설치 정보, 설정 예제, 호스트별 차이와 점검 방법을 관리하는 영역입니다. 종류별 하위 디렉터리는 실제 연동을 추가할 때 만듭니다. 외부 원본 전체나 실제 인증값은 이 저장소에 보관하지 않습니다.

| 종류 | 현재 범위 |
| --- | --- |
| 외부 스킬 | [선택한 스킬의 고정 커밋 설치·갱신·제거](../../docs/external-skills.md) 지원. 기본 전역·프로젝트 설치와 별도 |
| MCP | 레지스트리 항목과 설정 생성·health check 기능은 아직 없음 |
| 플러그인 | 레지스트리 항목과 자동 설치 기능은 아직 없음 |
| 외부 도구 | 외부 스킬이 요구하는 브라우저·바이너리·의존성은 별도 준비 |

제품 개발 워크플로우는 외부 스킬 체인을 강제하지 않습니다. gstack, Superpowers 같은 외부 스킬은 현재 작업에 필요한 능력을 개별 선택합니다. 파일 전달만으로 공급자의 플러그인·훅·설정이나 실제 호스트 실행이 준비됐다고 보지 않습니다.

출처와 검토한 커밋은 [레지스트리](../registry/README.md)가 소유합니다. 로컬 보정이 필요하면 [스킬 관리](../skills/README.md#작성과-외부-자산)의 wrapper 기준을 따릅니다.

## 공급자별 사용 안내

- [Modern Web Guidance](skills/modern-web-guidance/README.md)는 웹 UI·브라우저 API·호환성 가이드와 현대화 조사를 지원합니다. 검토한 CLI 버전을 호출하고 사용 통계를 끄는 실행 방법을 안내합니다.
